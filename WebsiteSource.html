My Personal Website

Problem Description
I wanted a quiet, simple corner of the internet where my engineering work, my writing, and my creative side could live together.

Execution
I built this site by forking a repository which appealed to me which used plain HTML, CSS, and JavaScript. I put together simple sections for my journey, articles, and projects, and hosted it on GitHub Pages so I can keep tweaking it as I go.

Future Scope
I plan to keep refining the layout, add more articles and projects and build out a space for my art as this site slowly grows with me.
