Problem Description
While trying to stay fit and lose weight, I struggled with apps to display information according to my needs

Technical skills in this Project

Primary language: C#
Framework: ASP.NET Core Minimal APIs on .NET 10
Database: SQLite
Database access:Microsoft.Data.Sqlite with SQL queries and parameters
API documentation: OpenAPI
Architecture: Service/repository pattern with dependency injection
Programming concepts: Async/await, cancellation tokens, REST HTTP endpoints, CRUD operations, model validation, and configuration
Supporting formats: JSON, HTTP, and .http API request files
It is primarily a RESTful backend API for step entries and user settings, with no frontend framework in the project.
